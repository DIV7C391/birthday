POOJA BIRTHDAY WEBSITE

1. Extract this folder.
2. Open the folder in VS Code.
3. Add photos to assets/photos using the filenames listed in ADD_PHOTOS_HERE.txt.
4. Add an MP3 to assets/music/your-song.mp3.
5. Edit the memory captions and letter in index.html.
6. In VS Code, install the Live Server extension, right-click index.html, and choose 'Open with Live Server'.

To publish and get a shareable link: push the folder to a GitHub repository, then go to Settings > Pages > Deploy from a branch > main > /(root) > Save. GitHub Pages will provide a public URL after deployment. Netlify Drop is another simple option: upload the project folder contents at https://app.netlify.com/drop.

Music note: browsers block autoplay; the visitor must press Play our song.
